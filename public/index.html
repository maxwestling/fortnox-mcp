Fortnox MCP Server

Connect Claude to your Fortnox account to work with customers, invoices, vouchers, and more.

Server URL

https://fortnox-mcp.vercel.app/mcp

Claude.ai or Claude Desktop

  1. Open Settings → Connectors.
  2. Click Add custom connector.
  3. Paste the server URL above and save.
  4. Click Connect and sign in to Fortnox to authorize access.

Claude Code

claude mcp add --transport http fortnox https://fortnox-mcp.vercel.app/mcp

Then run /mcp in Claude Code and authenticate with Fortnox.

You need a Fortnox account with permission to use integrations.
